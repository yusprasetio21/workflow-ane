# apps/
Place your main source code here as `apps/app/` (this folder is ignored by git):

    # Option 1: copy existing project
    cp -r /path/to/your/project apps/app

    # Option 2: clone your repo
    git clone <your-repo-url> apps/app

Folder name must be `app` (matches AGENTS.md and map/INDEX.md default).
